개인정보처리방침

"업무일상관리 연동"(이하 "앱")은 앱을 만든 개인 한 명만 사용하는 개인용 도구입니다. 시행일: 2026-10-06

1. 접근하는 Google 사용자 데이터

앱은 사용자가 승인한 범위에서 본인의 Google 캘린더 일정과 Google Tasks 할 일을 읽고, 만들고, 수정하고, 삭제합니다. 그 밖의 Google 데이터(메일, 드라이브 파일, 연락처 등)에는 접근하지 않습니다.

2. 이용 목적

사용자 본인의 일정·할 일을 앱 화면과 Google 캘린더·Tasks 사이에 동기화하는 용도로만 사용합니다. 광고, 분석, 판매, 제3자 제공에는 사용하지 않습니다.

3. 저장과 보관

데이터는 사용자 본인의 개인 컴퓨터와 본인의 Google 계정에만 있습니다. 앱 운영자가 별도의 외부 서버에 사용자 데이터를 수집·저장하지 않습니다.

4. 제3자 제공·공유

사용자 데이터를 제3자에게 제공하거나 공유하지 않습니다.

5. 삭제와 권한 철회

사용자는 언제든 Google 계정의 앱 권한 관리에서 이 앱의 접근 권한을 철회할 수 있으며, 앱이 만든 일정·할 일은 Google 캘린더·Tasks에서 직접 삭제할 수 있습니다.

6. Google API 서비스 사용자 데이터 정책

이 앱의 Google API 정보 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

7. 문의

이 저장소의 Issues 메뉴로 문의할 수 있습니다.
